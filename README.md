## Objectives

## Common Password Attacks

### Brute Force Attack
A brute force attack involves repeatedly attempting different password combinations until the correct password is discovered.

### Dictionary Attack
A dictionary attack uses a list of commonly used passwords and words to attempt unauthorized access.

### Credential Stuffing
Credential stuffing occurs when attackers use stolen usernames and passwords from previous data breaches to access other accounts.

### Phishing
Phishing attacks trick users into revealing passwords through fraudulent emails, websites, or messages.

## Password Security Best Practices

- Use strong and unique passwords
- Enable Multi-Factor Authentication (MFA)
- Avoid password reuse
- Use a password manager
- Update passwords when compromise is suspected
